# GENESIS Memory — landing page

React 19 · Vite 7 · Framer Motion 12. Every capability on the page is a working simulator
(spool collapse, prompt-diet slider, privacy-shield sandbox running the real detector port,
cross-client conduit, Hebbian sleep visualiser, universal client matrix with `export-config` tabs).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm run preview    # http://localhost:4173
```

Structure: `src/components/*` (one file per section), `src/lib/hooks.js` (pointer parallax,
in-view, counters), `src/lib/shield.js` (browser port of `genesis_memory/core/privacy_shield.py`).
