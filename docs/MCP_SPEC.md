# GENESIS Memory MCP Tools Specification

> Auto-generated by `scripts/gen_mcp_spec.py` from

> `*` marks a required parameter.

The Model Context Protocol (MCP) server runs via standard I/O (JSON-RPC)
and exposes the following tools
(19 cognitive tools + 1 `genesis` gateway tool):

| Tool Name | Parameters | Description |
|---|---|---|
| `remember` | `text` (string) *, `kind` (string (fact/decision/outcome)), `project` (string), `utility` (number), `supersedes_id` (integer) | Store one episodic project memory (fact, decision, or outcome). Returns id. Can supersede previous memory. |
| `recall` | `query` (string) *, `project` (string), `limit` (integer), `max_tokens_estimate` (integer), `snippet_words` (integer) | Retrieve relevant active memories (snippets, default 40 words each). Never silently truncates: reports budget use. |
| `forget` | `id` (integer) * | Delete one memory by id (human veto / correction). Returns deleted count. |
| `invalidate` | `id` (integer) *, `superseded_by` (integer) | Mark a memory as invalidated or superseded without deletion (MESI coherence). Preserves causal audit trace. |
| `resolve_conflict` | `conflict_id` (integer) *, `action` (string (superseded/kept_both/dismissed)) *, `winner_id` (integer) | Resolve a staged concurrent conflict from the Sleep Report Veto Queue. |
| `get_dependencies` | `source` (string) *, `depth` (integer) | Retrieve AST-extracted code dependencies (graph closure) for a module or file path. |
| `attest_closure` | `entity` (string) *, `context_text` (string) *, `depth` (integer), `threshold` (number) | Audit and attest working context completeness against active deterministic AST dependency closure. |
| `genesis_log` | `id` (string) *, `grep` (string), `lines` (integer), `offset` (integer) | Dereference and read full spooled command output by id. Supports grep keyword search and pagination. |
| `status` | none | Daemon health: counts, DB bytes, RSS MB (self-measured), uptime, call stats, active vs superseded. |
| `thread_update` | `topic` (string) *, `summary` (string) *, `recent_files` (string), `pending_focus` (string), `client` (string) | Update the unified cross-client active working thread so all AI clients share seamless context. |
| `thread_get` | none | Read the unified cross-client active working thread. |
| `dialogue_update` | `session_id` (string), `client` (string), `user_prompt` (string) *, `assistant_summary` (string) *, `salient_terms` (string) | Record 1-turn cross-session dialogue exchange into dialogue_buffer (sanitized & bounded). |
| `dialogue_get` | `session_id` (string), `max_age_s` (number) | Retrieve the latest 1-turn cross-session dialogue exchange (TTL 1800s). |
| `cross_client_resolve` | `question` (string) *, `max_chars` (integer) | Resolve a cross-client follow-up in ONE call: thread, fresh dialogue, episodic recall, then local client storage. Returns provenance-labeled answer or resolved:false (say unknown, never invent). |
| `reinforce` | `id` (integer) *, `outcome` (string (success/failure)), `note` (string) | Reinforce (+1) or penalize (-1) a memory engram based on task outcome and feedback (Hebbian learning). |
| `synthesize_skill` | `name` (string) *, `action_recipe` (string) *, `trigger_patterns` (list[string]), `preconditions` (string), `invariants` (string), `confidence` (number) | Persist a deterministic procedural skill / actionable recipe with trigger patterns into procedural memory. |
| `skill_recall` | `query` (string) *, `min_confidence` (number), `limit` (integer) | Recall procedural skills and actionable recipes matching a prompt, keyword, or error pattern. |
| `sleep_now` | `deep` (boolean) | Trigger an immediate biomimetic sleep consolidation cycle (Hebbian decay, skill extraction, Active Digest generation). |
| `challenge_rule` | `solidified_id` (integer) *, `proposed_text` (string) *, `reason` (string) | Challenge a solidified golden rule with a better alternative. Registers a conflict for user review instead of silently complying with a possibly outdated rule. |
| `genesis` | `op` (see gateway ops) * | GENESIS memory gateway: every memory op through one tool, keeping per-turn context small. Op args pass through unchanged; {op:'help'} lists op shapes. Ex: {op:'recall', query:'...'}. |

Set `GENESIS_MCP_TOOL_MODE=gateway` to advertise only the single
`genesis` tool (all ops route through it with identical arguments).
